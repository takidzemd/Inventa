Инвентаризация

Распределение задач по сотрудникам
Импорт графика
Загрузите файл графика, чтобы система нашла сотрудников.
Выберите сотрудников
Снимите галочки с тех, кто не участвует в инвентаризации.
Импорт категорий
Загрузите файл «группы.xlsx». Цвета ячеек задают правило: красная — не делить, оранжевая — объединять при распределении, белая — делить по имеющимся подкатегориям.
Проверьте категории
Оставьте галочки на категориях, которые нужно распределить.
Готовы к распределению?
Цветовые правила из загруженного Excel определяют деление. Красные строки остаются целыми. Оранжевые строки объединяются внутри своей основной категории. Белые делятся по реальным подгруппам с количеством, в том числе без числового кода. Цель по разнице — до 100 единиц, если доступные группы это позволяют.
Результат распределения
Обновить — назначить другие группы сотрудникам, не меняя цветовых правил.
