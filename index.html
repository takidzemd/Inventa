Распределение задач по сотрудникам

Руководство по разделам

Шаг 1: График

— загрузите график работы из 1с (Экспортируйте Excel файл), чтобы система автоматически нашла всех сотрудников.

Шаг 2: Сотрудники

— проверьте список и снимите галочки с тех, кто не участвует в распределении.

Шаг 3: Категории

— загрузите файл категорий для подсчета (Обновите куб под свое подразделение).

Шаг 4: Проверка

— оставьте галочки только на тех категориях, которые нужно распределить.

Шаг 5: Запуск

— нажмите «Запустить распределение». Программа сбалансирует нагрузку.

Шаг 6: Результат

— скачайте готовый PDF или нажмите «Обновить» для генерации нового варианта.
